## 1. Project Overview
**UTM FitMate and Court Buddy** is a responsive campus sports coordination web application designed for UTM students. It brings sports partner discovery, session management, venue booking status updates, and participant group communication into a single platform.

## 2. Core Subsystems
* **User and Fitness Profile (6.4):** UTM email verification, sports preferences, skill levels, availability schedules, and privacy settings.
* **Activity Management (6.5):** Session creation/publishing, organizer-reported venue booking status, participant capacity limits, and event rules.
* **Matching and RSVP (6.6):** Session filtering, compatibility ranking (by sport, skill level, and availability), open joining, organizer approval, and waitlist management.
* **Chat and Achievement (6.7):** Confirmed-participant group chat, attendance tracking, participation milestones, and reliability reporting.

## 3. Technology Stack
* **Frontend:** Vue.js 3, TypeScript, Tailwind CSS
* **Backend:** FastAPI (Python)
* **Database:** SQLite
* **Collaboration Tools:** GitHub & Trello
